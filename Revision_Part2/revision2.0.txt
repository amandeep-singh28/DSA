- Java Interning
Suppose we have decalred a string with a variable 'str1' and its value is "Hello". Now we have created a new literal 'str2' but with the same value "Hello". So, both 'str1' & 'str2' will point to the same value.
If you want to avoid interning, use 'new' keyword.
